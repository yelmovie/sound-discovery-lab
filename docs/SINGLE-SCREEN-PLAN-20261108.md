# 실험 한 화면·자동실험 구현 기준

사용자 요청: 모든 스테이지에서 실험 장면과 필수 조작을 스크롤 없이 동시에 표시한다. 실험 면적을 넓히고 중복 안내를 없애며 다음 조작을 표시한다. 속도를 선택하는 자동실험을 제공하되 답은 학생이 직접 결정한다.

- 제목·4단계 이동, 실험대, 고정 하단 조작줄의 3행 구조. 큰 친구 안내 카드와 반복 목표·요약을 없애고 다음 행동 안내는 한 곳에만 둔다.
- 기기 폭·높이에 따라 실험의 그림과 조작을 좌우 또는 위아래로 재배치한다. 실험과 선택지를 숨기거나 스크롤로 넘기지 않는다. 필요한 마지막 크기 보정은 실제 비율을 검사 결과에 남긴다.
- 다음 조작이 단일 버튼이면 해당 버튼을, 답을 고르는 단계이면 선택지 묶음 전체를 강조한다. 정답을 암시하지 않는다.
- 자동실험 속도는 0.5·1·1.5·2배. 단계 사이 대기 시간만 바꾸며 실험 음높이는 유지한다. 사용자 재생 버튼을 누를 때만 시작한다.
- 관찰·청음·세기 및 길이 비교는 기존 조작 경로로 실행한다. 정답 선택, 진단, 분류, 배치, 목표 연주 등 답이 되는 조작은 자동 제출하지 않는다. 필요한 시연은 실제 답·증거와 분리된 일시적인 그림·소리로 보여 준다.
- 일시정지·정지·속도 변경을 제공한다. 수동 조작, 화면 전환, 모달, 탭 숨김에서 재생을 취소하고 남은 타이머가 다른 화면을 조작하지 못하게 한다. 다음 활동은 자동으로 넘기지 않는다.
- 저장 형식·정답 판정·기존 증거를 유지한다. A/B 재생은 기존 A를 보존하고 다른 세기의 B를 만든다.
- 검증: 재생기 상태·취소·속도·정답 미제출 단위 테스트를 먼저 작성. 기존 기능 테스트, 구문 검사, 빌드. 20활동×8크기와 긴 라운드·완료·오답 상태의 스크롤·넘침·필수 조작 가시성·겹침·다음 타깃을 브라우저에서 확인한다.

분담: 공통 화면·기존 활동·앱 연동(root), 자동실험 모듈 및 단위 테스트(experiment_visuals), 의뢰 활동 배치 및 중복 문구(challenge_design), 브라우저 검증(responsive_qa). 모든 산출물·캐시는 외장 SSD에 둔다.
