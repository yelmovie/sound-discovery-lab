# 11 울림도시 대작전 · 지도 악당 연계 계획

2026-11-14 · 지도 악당의 초기 시안과 구현 계획을 남긴 기록. 아래 대사와 연출은 당시 제안이며 현재 게임에서는 달라진 부분이 있다. 실제 구현은 [등장과 전투](../src/map-encounters.js), [장소별 대사](../src/map-villain-content.js), [마무리 영상](../src/map-finale.js)에서 확인할 수 있다.

공통 인수인계와 15개 지도 합성 시안은 외장 SSD의 프로젝트 공용 작업 폴더에 보관했다. 운영 주소는 [울림도시 대작전](https://sound-discovery-lab.yelsam.workers.dev/)이다.

## 외형과 등장

**방해 스피커 / 보라 우퍼, 굵은 주황 플러그와 청록 코어.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

소리를 꺼도 파형과 플러그 분리로 읽혀야 한다. 수업 환경에서 지속 노이즈 대신 짧고 볼륨 낮은 타격음.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 진동 연구소 | 우퍼 진동판을 한 번 크게 움찔 | “이 떨림, 내가 켰지!” |
| 볼륨 경기장 | 볼륨 손잡이를 쓱 돌리기 | “아직 더 키울 수 있지!” |
| 조율 공방 | 소리판을 한 칸 어긋나게 밀기 | “멜로디를 한 칸 틀어 볼까?” |
| 전달 네트워크 | 코어 플러그를 빼서 흔들기 | “신호선을 뽑아 버렸지!” |
| 소음 관리센터 | 작은 전원등을 켰다 끄며 깐죽대기 | “조용하니까 심심한데?” |

상황 대사 예시:

- 접근: “이 플러그는 내가 뽑았어!” / “도시가 너무 조용했거든!”
- 1·2타: “앗, 우퍼가 덜덜!” / “내 손잡이가 헛돈다!”
- 퇴장: “전원이 푹 꺼졌네!” / “이번엔 조용히 갈게!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 가느다란 원형 음파 한 겹 |
| 2타 · 더 큰 반동 | 원이 두 겹으로 겹치고 우퍼가 눈에 띄게 눌림 |
| 3타 · 마무리와 퇴장 | 전원 빛이 푹 꺼지고 짧은 신호 반짝임만 남음 |
| 주인공 접촉 | 주인공은 양손으로 귀를 가리고 한 발 물러남 |
| 보조 캐릭터 접촉 | 동료는 몸을 납작하게 하고 한 번 반동 |
| 악당의 접촉 공격 동작 | 우퍼가 뒤로 당겨졌다 한 번 볼록해짐. 접촉 지점에서 작은 음파 한 겹만 표시. |
| 타격·퇴장 효과음의 차이 | 둥 → 덜덜 → 푹 |
| 접촉 효과음 모티프 | ‘둥–푹’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

우퍼와 공격 음파는 상대 쪽을 향하게 하고, 뽑힌 플러그와 코어 사이의 간격은 두 자세에서 모두 보이게 한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/data.js](../src/data.js) · [src/map.js](../src/map.js) · [src/map-world.js](../src/map-world.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

이 시안을 작성할 당시에는 정적 이미지 합성과 계획을 완료했다. 06 물의 상태 변화는 참고용이었다.
