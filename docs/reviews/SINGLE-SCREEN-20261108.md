# 단일 화면 학습·자동 재생 검증 — 2026-11-08

20개 활동을 8개 화면 크기로 검사했다. 기본 160조합과 긴 문제·완료·오답·부분 진행·재생·교사용 상태를 합친 **282상태에서 스크롤, 화면 밖 필수 조작, 숨겨진 필수 조작, 버튼 가림, 글자 잘림, 아이콘 겹침, 반복 문장 오류 0건**을 확인했다. 실제 조작 영역은 모두 44px 이상이었다. JavaScript와 HTTP 오류도 0건이다.

## 결과

활동은 제목·실험대·다음 행동 안내의 세 행으로 구성한다. 실험 그림과 조절·비교·선택지를 한 화면에서 함께 볼 수 있고, 다음에 누를 조작 또는 선택지 그룹을 강조한다. 여러 곳에 반복되던 안내와 오답 피드백은 하단 한 곳에 모았다. 노트·개념 영상·지도·교사용 이동은 보조 메뉴로 제공한다.

자동 재생은 관찰과 청음을 진행한다. 정답 선택, 멜로디 답안 연주, 전달 물질 선택, 정답 도구 배치는 학습자가 직접 수행한다. 속도는 0.5·1·1.5·2배이며, 관찰 간격만 바꾸고 소리의 높낮이나 세기는 바꾸지 않는다.

## 실제 UI 기능·회귀 확인

기능·회귀 25항목을 실제 브라우저 이벤트로 통과했다.

- 재생·일시정지·이어 재생과 네 속도 선택, 일시정지 중 추가 진행이 없는지 확인했다.
- 10종 의뢰를 새 상태에서 자동 관찰해 답안·배치·proof·증거를 자동 생성하지 않는지 확인했다. 소리 상자의 청음 대상 선택은 관찰 상태로 구분하고 정답 슬롯 배치는 바꾸지 않는다.
- 이미 고른 오답 도구를 유지하고, 학습자가 먼저 고른 정답 도구의 전후 관찰을 마치면 기존 판정으로 정확히 한 라운드만 완료되는지 확인했다.
- 1배와 2배에서 소리 엔진에 전달되는 주파수·세기·음원 길이가 같은지 확인했다.
- 수동 조작, 모달, 이동, `visibilitychange`와 `pagehide`에서 재생과 후속 상태 변경이 멈추는지 확인했다.
- 임시 미리보기 중 모달을 열면 원래 그림으로 돌아오는지, 원래 소리가 끝날 만큼 오래 쉬었다 재개해도 소리굽쇠를 다시 울리고 멈출 수 있는지 확인했다.
- 보조 메뉴의 노트·개념 영상·자막·닫은 뒤 포커스 복원과 최종 질문의 다음 문제 이동을 확인했다.

오답 안내와 자 카드 그림은 최종 13상태를 추가 검증했다. 틀린 소리 주문은 조절 영역, 틀린 해결 도구는 도구 전체 그룹으로 안내하며 정답 값은 선택하지 않는다. 오답 문장은 하단 한 곳에만 표시한다. 자 카드의 내부 고정부품은 전체 그림의 크기 규칙을 상속하지 않도록 분리했고, 1920·1280·390px 화면에서 막대와 고정부품이 연결된 모습을 직접 확인했다.

통합 기능 테스트 88개와 구문 검사는 통과했다. 최종 빌드도 71개 에셋·44개 사전 캐시로 통과했다. 제품 소스의 시작·종료 해시는 전체 검증과 추가 검증 각각에서 동일했다.

하네스는 실제 화면 제목, 필수 조작 수량, 문서·본문·실험대·내부 영역의 높이와 너비, 텍스트 Range, 아이콘 경계, 중심점 hit-test를 확인한다. 스크롤로 다시 보이게 하거나 필수 조작을 CSS로 숨긴 경우는 실패다. 높이·너비 비교는 경계·소수점 계산 차이 3px까지, 44px 조작 판정은 0.5px 미만의 소수점 오차만 허용하며 실제 조작의 가시성과 가림을 별도로 검사한다. 닫힌 보조 모달과 접근성 전용 문구는 화면 겹침 대상으로 세지 않는다.

물리 태블릿·Safari 터치와 스피커 청음은 미실측이다. 소리 검증은 브라우저 동작과 엔진에 전달되는 매개변수 기준이다.
