## 배포물 검증

- Python copyfile로 확장 속성 없이 별도 staging에 복사한 뒤 생성 메타파일만 정리했다. `._*`·`.DS_Store`는 배포 전후0개. 원본 메타파일은 삭제하지 않았다.
- 최신 원격 SHA·원본 clean·staging의 모든 파일 해시를 실제 배포 직전 다시 확인하고 실패하면 중단하도록 연결했다.
- 공개 주소150/150 파일 SHA-256 일치. 첫 병렬 읽기에서2개가 시간초과였고, 그2개만 curl 재확인해 모두 일치했다.
- `/._index.html`, `/.DS_Store`, `/src/._app.js`, `/image/generated/._explorer-walk.webp`는 실제404 응답, 본문 없음.
- 비밀값·문서·테스트·원본 에셋 보관함은 배포하지 않았다. 기존 지도 PNG/JPG 복사본3개는 runtime에서 빠지고 원본 소스는 유지된다.

## 운영 브라우저 확인

독립 Chrome의1280×800,1024×768,915×412에서 다음을 확인했다.

- 시작→지도→첫 활동→자동 관찰→오답→정답→저장→실제 새로고침→설정/Esc→다음 활동.
- 자동 관찰만으로 정답 증거가 생기지 않고, 오답도 증거를 주지 않으며, 맞는 답 후 관찰 기록이 새로고침에서 보존됨.
- 학습 이미지가 실제 디코드된 뒤 스크린샷과 읽기·터치 검사를 수행. 각 첫 활동의 최소 글자16px, 조작48px.
- 실제 JS/HTTP 오류0, 외부 도메인 요청0. 화면 전환과 지도 제한시간의 `ERR_ABORTED`는 별도 취소 목록으로 보존했다.
- 별도 정상 서비스워커 설치 후 네트워크 차단·새로고침으로 지도 표시 PASS.
- 마지막 실행 첫 화면 준비:3118ms,3507ms,2253ms. 로컬 제한망 실측과 다른 환경이며 속도 개선으로 해석하지 않는다.

## 확인한 지연과 한계

운영 검증 중 지도 그림의 로드가 기존25초 제한을 넘긴 세션들이 있었다. 앱은 ‘다시 불러오기’와 기록 보존 안내를 표시했다. 일부 실행은 재시도3회 뒤에도 완료되지 않았으며 이 실패 기록을 남겼다. 마지막3해상도 실행은 모두 완료됐고1280에서는 실제 재시도1회, 나머지는0회였다. 원인이 해결됐거나 모든 학교망에서 재현되지 않는다고 주장하지 않는다.

파일은 모두 정확하고, 독립 이미지 디코드 검사는3장 모두1.66초 및4.25초에 완료됐다. 두 번째 실행은 `--disable-http2`를 넣었으나 실제 전송이 둘 다h3라 HTTP/1 비교라고 해석하지 않는다. 배포 진단 중 앱 코드를 임의 수정하거나 재배포하지 않았다.

첫 하네스는 화면 전환의 정상적인 요청 취소도 오류로 집계했다. 취소와 실제 JS/HTTP 오류를 구분하고 이미지 완전 로드를 추가한 뒤 다시 검사했다. 숨겨진 실패를0으로 바꾼 것이 아니라 실패 시도·실제 재시도·취소 요청을 각각 기록했다.

기존8.7점은 통합 전 검토의 점수다. 이번 운영 확인은 배포 후 smoke 미검증을 보강하지만 새로 관찰한 연결 지연도 있어 단순히 점수를 올리지 않았다. 실학생·학교 실기기·교사 검수·원본 권리·작은 휴대폰 화면·실제 스피커 청취 조건은 남는다.
