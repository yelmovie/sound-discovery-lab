## 발견한 미적용 두 건과 복구

### 작은 화면의 축하 신호 건반

기록은 도→미→솔 건반이 높은 음일수록 짧아진다고 설명한다. 기본 CSS는110→102→93px였지만 높이650px 이하 규칙이 세 건반을 `70px!important`로 덮었다. 기존 회귀 테스트는 기본 규칙만 검사해 이 문제를 놓쳤다.

작은 화면의 최소 높이를110→100→90px로 복구했다. 연주 뒤 표시되는 긴 글 때문에 높이가 같아지는 경우까지 브라우저에서 확인하고 조정했다. 작업대 설명은 태블릿14px·전자칠판18px, 시설 선택은48px로 보정했다. 작은 화면 규칙을 기존 테스트에 추가해 실패 재현 후 통과를 확인했다.

### 빌드 폴더에 남은 이전 파일

현재 실행 목록은 최적화한 JPG·WebP와 새 MP3를 참조하지만, 재사용한 `dist`에 이전 PNG·효과음·AAC 파일15개가 남아 있었다. 첫 공개 파일 검사에서 이 파일들도 실제 배포된 것을 확인했다. 이전 기록의 불필요한 원본 배포 제외가 전체 빌드에 적용되지 않은 상태였다.

기존 `dist` 사본을 외장 SSD에 보관한 뒤 빌드가 출력 폴더를 새로 만들도록 수정했다. 의도적으로 넣은 잔여 파일이 재빌드 후 사라지는 회귀 검사도 수행했다. 배포 대상은153개·46,717,246바이트에서138개·20,489,481바이트로 줄었다. 제외한15개 합계는26,227,921바이트다. 코드·캐시 버전의 소규모 변화로 총량 차이와 제외 합계에는 차이가 있다.

`npc-welcome.m4a`, `drop_001.ogg`, `maximize_008.ogg`는 후속 기록에서 각각 새 환영 MP3, 나무 타격음, 복구 편곡으로 교체된 파일이다. 현재 코드가 참조하는 대체 파일의 포함 여부를 확인했다. 원본 소스와 기존 제작 기록은 보존했다.

## 공개 주소 검증

- 운영 버전 `63a7ee7c-a75f-4e4f-8e12-d0459fc7bc76`에 트래픽100% 적용을 확인했다.
- 최종138개 파일의 공개 응답은 로컬 검증본과 SHA-256이 모두 일치한다. Git blob과는134개가 바이트 단위로 일치하고,3개는CRLF/LF 줄바꿈만 다르다. 해당 파일은 `src/manipulations.js`, 두 음원 출처 JSON이다. `sw.js`는 검증 빌드에서 캐시 버전과 프리캐시 목록을 생성한다. 영상1개에서 첫 전송 시간초과가 있었고 재시도해 일치했다.
- 메타파일·`.git`·`.env`·검토 문서 경로는404였다. 제거한 배포 잔여 파일15개도 모두404였다. Python urllib의403 응답은 별도 전송 검사 기록으로 남겼고 일반 fetch로 다시 확인했다.
