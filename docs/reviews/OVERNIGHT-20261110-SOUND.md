# 7번 소리 프로젝트 고도화 검증

후속 상태: 아래 평가는 통합 전 시점의 기록이다. 원본 통합·push·운영 배포 및 실제 검증 결과는 `DEPLOY-20261110-OVERNIGHT.md`에 추가했다.
## 결과와 작업 경계

시트 7, 폴더 `11 sound`, 기준 커밋 `222374d`. 격리 브랜치 `codex/overnight-sound-20261110`에서만 작업했다. 원본 병합·push·공개 배포는 수행하지 않았다. 시트 1~6, 원본 그림, 글꼴, 음성 29개, 학습 순서, 저장 형식, 채점 규칙을 변경하지 않았다.

초등 과학 설명과 실제 조작의 연결을 먼저 검토했다. 현재 앱은 5시설의 20활동, 도전 34라운드, 개념영상 5편, 마지막 과제 5개와 인증서로 이어진다. 오답에는 관찰 근거를 다시 찾는 안내를 주고, 자동 관찰은 관찰 기록까지만 채우며 최종 응답은 학생이 한다. 새 악당이나 보상 체계를 덧붙여 이미 검증된 학습 구조를 흔들지 않았다.

## 적용한 개선

1. **의미가 맞는 아이콘.** 소리 전달 물질의 공기·물·고체에 쓰던 파형·네트워크·음표 대신 바람·물방울·입체 블록을 사용하고, ‘듣는 곳’은 귀 아이콘으로 바꿨다. 텍스트 이름도 유지한다. 별도의 이미지 다운로드나 추가 패키지는 없다.
2. **기존 스프라이트의 용량 개선.** 탐험가와 새의 스프라이트를 같은 크기의 무손실 WebP로 바꿨다. 불투명/반투명 픽셀의 RGBA 비교 변화는 0이다. 지도는 같은 해상도의 품질 90 WebP로 바꾸고 실제 화면을 열어 확인했다. 3개 합계 3,719,901 → 2,812,600바이트, 907,301바이트(24.4%) 감소. 기존 원본은 보존하고 빌드 출력의 이전 3개 복사본만 제거한다. 탐험가 1.15MB는 아직 1MB 경고 기준을 넘는다.
3. **관찰 피드백 애니메이션.** 반복 box-shadow 펄스를 transform/opacity와 선 테두리로 바꿨다. 테두리는 컨트롤 내부에서만 움직이고 입력을 가리지 않는다. ‘움직임 줄이기’에서는 펄스 없이 관찰 상태를 표시한다. 과학 개념인 물체 떨림은 유지한다. 앱 전체의 모든 애니메이션 비용이 해결되었다는 뜻은 아니다.
4. **태블릿·가로 화면 조작 크기.** 축소 배율을 보정해 주요 활동 버튼·슬라이더의 실제 크기를 48px 이상으로 유지한다. 헤더·하단 일부 컨트롤도 48px로 보완했다. 레이아웃 수렴 반복을 제한 10회로 늘려 확대된 조작부가 잘리지 않게 했다. 좁은 휴대폰 세로는 기존 44px 기준을 유지했다.
5. **읽기 크기 회귀 방지.** 전수 검사에 1024×768을 추가하고 1920 폭의 18px, 900~1799 폭의 14px 실제 글자 하한을 검사하도록 강화했다. 여기서 발견한 1024×600 진단 선택지 및 작은 화면 재도전 라벨 축소를 보정했다. 글꼴 종류는 바꾸지 않았다.

## 최종 실측

- 119/119 단위 테스트, 문법·빌드 PASS.
- 정상 학생 완주 139체크·486화면 검사, 오류·런타임 오류·중간 수리 0. 검사 중 소스 해시 변경 없음.
- 302상태 전수 검사, 지정된 레이아웃/읽기 하한 오류 0, 런타임 오류 0. 좁은 보조 화면의 작은 글자는 별도 경고로 유지.
- 첫 화면 cold 107ms, 10Mbps·40ms 2612ms, 각 약2.99/2.97MB. 제한망 FCP 516ms.

## 검증 범위

- 문법 검사, 119개 단위 테스트, production 빌드.
- 정상 학생 UI 완주: 관리자 모드·강제 해금·저장값 주입 없이 20활동/34라운드/5개 영상/최종 5과제/인증서. 실제 새로고침·관찰 복원·오답 재시도·지도 이동도 검사한다.
- 9뷰포트 및 교사·완료·자동 관찰 보조 상태를 포함한 302상태 전수 검사. 이 검사는 적법한 상태를 주입하는 레이아웃 검사이며 정상 학생 완주와 구분한다.
- 별도 실행: 물질 아이콘 3종 구분, 틀린 물질에 증거 0개/맞는 물질에 1개, reduced-motion 펄스 정지와 관찰 상태, 네트워크 차단 후 지도와 새 WebP 3개의 200 응답.
- 캐시·서비스워커를 끈 로딩 실측과 10Mbps·40ms 조건. 지도 에셋은 지연 로드이므로 첫 화면 속도의 개선분으로 주장하지 않는다. 측정값은 같은 컴퓨터의 동시 작업에 영향을 받는 참고값이다.
- 제공 교육과정 PDF 15쪽과 세 성취기준 문장을 실제 대조했다. 자세한 내용은 `overnight-20261110/curriculum-check.md`.

정확한 최종 수치는 `overnight-20261110/validation-summary.json`과 각 JSON에 기록한다. 전체 원시 스크린샷은 격리 worktree의 `.tmp/single-screen-20261108/final-reading-fixed` 및 `.tmp/full-play-20261109/overnight-final-reading-floor`에 보존한다. 대표 화면은 이 보고서와 함께 저장한다.

## 실행 명령

```sh
npm run check
npm test
npm run build
QA_BASE=http://127.0.0.1:4278 node scripts/qa-single-screen.mjs final-reading-fixed
QA_FAIL_FAST=1 QA_BASE=http://127.0.0.1:4277 node scripts/qa-full-play.mjs overnight-final-reading-floor
```

기존 설치 Chrome과 Playwright를 사용했다. 서버 4278은 소스, 4277은 production 출력이다. 기존 검증 프로필을 덮어쓰지 않는다. 최종 검사 중 소스 해시가 바뀌지 않았는지도 결과 파일에서 확인한다.

## 불리한 시도도 확인하고 되돌림

- 처음 만든 테두리의 바깥쪽 확장이 작은 화면에서 4px 넘침을 일으켜 안쪽에서만 움직이도록 수정했다.
- 휴대폰 세로에도 48px를 강제하면 전체 활동 축소로 기존 9.8px 글자가 6.9px까지 작아져 해당 범위는 기존 44px를 유지했다.
- 새 프로필 이름이 이미 존재한 한 완주 실행은 하네스가 안전하게 거부했다. 이전 기록을 삭제하거나 이어쓰기하지 않고 새 이름으로 최종 실행했다.
- 로컬 오프라인 검사는 앱의 개발용 서비스워커 비활성화를 고려해 `?sw`로 활성화했다. 이를 실제 공개 주소 검증과 혼동하지 않는다.

## 남은 제한과 배포 판정

**조건부 통합 가능. 만점 또는 납품 완료로 선언하지 않는다.**

- 교사 최종 검수, 학생 40분 수업 경험, 학교 실기기 터치·프레임·실제 스피커 청취는 확인하지 않았다. `needsReview:true`는 유지한다.
- 휴대폰 360×740의 완료 상태에서 가장 작은 설명이 약 9.8px이며, 극저높이 740×360에서는 9.7px다. 740×360은 조작부를 44→48px로 키운 대가로 일부 설명이 시작 10.1~10.2px보다 약 0.5px 더 축소된다. 915×412 이상 가로/태블릿/전자칠판을 권장한다. 302상태 오류 0은 지정한 검사 하한의 결과이지, 이 좁은 화면까지 읽기가 완벽하다는 뜻이 아니다.
- 일부 기존 44px 컨트롤, 큰 `app.js`, 색 하드코딩, 미사용 원본 시안 약 36MB, 탐험가 1MB 초과가 남았다. 시안은 배포물에 포함하지 않고 삭제하지 않았다.
- `src/signal-restoration.css`의 짧은 shadow/filter 효과, `src/style.css`의 지도 will-change 및 위치 전환 등 정적 성능 위험이 남아 D13 경고를 유지한다. FPS 저하를 실측한 것은 아니다.
- 기존 제공 에셋의 전체 상업 이용 권리 근거는 확인하지 못했다. 재인코딩은 새 권리 허가가 아니다.
- 원본 저장소 Git의 macOS `._pack*.idx` 인덱스 경고가 있었지만 정상 Git 인덱스는 동작했다. 기존 파일을 삭제하거나 손대지 않았다.
- 원본 통합 전 다른 작업의 HEAD/dirty 상태를 다시 확인하고, 통합 담당이 충돌 없이 병합·배포한 뒤 실제 URL smoke를 해야 한다.
