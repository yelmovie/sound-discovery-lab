## 실제 수행·수정

- source에서 20활동을 순서대로 모두 플레이해 증거20개·시설5개·최종복구·정식 인증서를 확인했다. 새로고침 후 완료와 증거가 유지됐다.
- 의미 없는 제출·틀린 판단·미선택 최종 답을 막고 같은 활동에서 재시도되는 것을 확인했다.
- 정렬의 세 번째 칸만 채운 뒤 새로고침해 앞 빈칸 두 개와 상자C 위치가 보존됨을 확인했다.
- 별도 테스트 origin의 관리자 해금에서 증거0·복구0을 유지하고, 최종 답이 모두 맞아도 인증서 인쇄가 없는 미리보기임을 확인했다. 해금 해제 후 원래 잠금으로 돌아왔다.
- 초기화 취소에 처음 초점이 갔고, 취소/초기화 후 소리 설정 유지와 처음 화면 복귀를 확인했다. v1 백업 삭제는 코드 확인, 이관·백업 보존은 단위 테스트로 검증했다.
- BGM을 끄면 음량 슬라이더가 잠기고, 양쪽 채널이 꺼져 있어도 상단 스피커로 둘을 다시 켤 수 있다. 성공 신호·조율·감지기의 실험음이 축하음으로 끊기던 문제를 수정하고 회귀 테스트를 추가했다.
- 지도는 1024×768·1280×800·1440×900·1920×1080에서 실제 viewport 크기를 읽고 확인했다. 가로 넘침0·지도 버튼48px미만0. 작은 화면에서 카메라 밖 시설은 걷기/목적지 이동으로 접근한다.
- 생성소품10개를 코어·링·소리굽쇠/받침·북/북채·칼림바/음판·발신/감지 장치에 연결했다. 외부 3D 프롬프트 캔버스도 20활동과 생성 완료 상태로 갱신했다.
- 최종 코드의 구문 검사·30테스트·dist 빌드가 통과했다. source와 dist 둘 다 브라우저에서 실행했다. 검증 중 발견한 콘솔 오류·경고는0개였다.

## 남은 확인과 우선순위

1. 납품 담당자가 기존 제공 이미지의 원본 생성·구입·상업 이용 근거를 확정한다. CREDITS의 확인 범위를 갱신한다.
2. 현장 담당자가 실제 태블릿 터치, 교실 스피커, 전자칠판 뒷자리, 인쇄/PDF를 확인한다. 학생의 설명과 생활 속 실천으로 학습효과를 평가한다.
3. 원격 제공이 결정되면 학교 Wi-Fi 30대·초기 다운로드·중단 복귀를 측정하고 이미지 압축/캐시를 검토한다. 현재 로컬 실행은 인터넷 연결 없이 가능하지만 서버를 켜 두어야 한다.
