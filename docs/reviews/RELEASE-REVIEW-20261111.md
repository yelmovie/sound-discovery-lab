3. 작은 가로 화면의 완료 화면을 가로 배치로 바꿨다. 진행판이 추가되면서 전체 내용이 줄어들던 문제를 해결했다.
4. 메인 로고가 남은 높이에 맞춰 조절되도록 했다. 1024px 태블릿에서 캐릭터가 음성 버튼을 덮던 문제와 하단 음량 안내 잘림을 해결했다. 좁은 화면에서는 장식 캐릭터를 숨긴다.
5. 개념 영상 글 설명의 펼치기 영역을 40px에서 48px로 키웠다. 휴대폰 지도에서 화면 밖으로 나가던 음성 버튼을 안내 상자 안에 배치했다.
6. 브라우저 검사를 실제 글꼴 로드 후 수행하고, 완료 상태·화면 크기 지정·44px 터치 기준 검출을 추가했다. 빌드 구문 검사는 모든 `src` JavaScript 파일을 대상으로 한다.
7. 사용자가 요청한 작업 기록 대조에서 축하 신호의 작은 화면 규칙과 오래된 빌드 잔여 파일을 발견했다. 건반 길이 순서와 읽기 크기를 복구하고, 빌드 출력이 매번 새로 만들어지도록 했다. 자세한 대조는 `RECONCILIATION-20261112.md`에 기록했다.

## 남은 제한

- 추가 검사한 360×740·740×360의 80상태에서는 일부 설명이 9.7~13.8px였다. 740×360의 떨리는 부분 찾기 작업 영역은 내용 높이가 5px 넘쳤다. 주 활동의 화면 밖 조작 버튼은 없었지만 이 작은 화면의 읽기 문제는 남겼다.
- 제한망 실험의 첫 화면 완성 시간은 10Mbps·40ms 설정에서 11.37~19.57초였다. 별도 초기 실행은 19.51~25.32초도 기록했다. 운영 주소의 일반 연결 실측은 4.44~6.02초, 약2.71MB였다. 측정 중 다른 프로젝트의 브라우저 작업이 병행됐으므로 실기기 대표값으로 일반화하지 않는다. 이전 보고서의 빠른 값을 이번 점수에 재사용하지 않았다.
- 초기 로딩 D1은 제한망에서 8초를 초과해 FAIL이다. 운영 일반 연결에서는 화면과 조작이 정상적으로 열리고 전체 완료 경로도 통과했다. 학교 연결 상태 확인을 조건으로 배포 가능 판정의 경미한 성능 예외를 적용한다. 느린 연결의 로딩 개선은 후속 과제로 남는다.
- 실제 태블릿·Safari·학교 네트워크·교실 스피커 청취·40분 학생 수업은 미검증이다. 터치는 Chromium 합성 입력으로 확인했다.
- `needsReview:true`를 유지했다. 기존 제공 이미지의 전체 상업 이용 근거와 일부 출처는 확인이 필요하다.
