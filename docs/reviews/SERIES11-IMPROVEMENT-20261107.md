# 11 sound · 울림도시 대작전 고도화

## 범위와 판단
2026-11-07. 1~5번은 완성본 기준이며 수정하지 않았다. 11번은 최근 지도 개선과 기존 20개 활동, 5개 개념 영상, 기록 음향 70개 자산 묶음을 유지한다. 사용자 데이터나 다른 프로젝트, 모모 서비스를 수정하지 않았다. 커밋·배포 없음.

이번 변경의 우선순위는 장식 추가보다 수업 기록 신뢰성이다. 기존 교사용 안내에는 원래 학생 진행으로 돌아간다고 쓰였지만, 실제로는 같은 state의 work/evidence를 바꾸고 localStorage에 저장했다. 오류·미지원 버전도 빈 상태로 읽힌 뒤 다음 조작에서 원본이 덮어써졌다.

## 실제 적용
- 교사용 전체 해금은 학생 상태의 메모리 복사본에서만 진행한다. 악기 조작·정답·증거·마무리를 학생 저장소에 기록하지 않는다. 종료/새로고침은 학생 진행으로 복귀한다. 시연 상태와 저장 안 됨을 화면에 명시한다.
- 구버전에서 저장된 admin 플래그는 시작 때 해제한다. 과거에 이미 섞인 시연/학생 증거를 임의 삭제하지 않는다.
- 손상 JSON·지원하지 않는 버전은 원문을 유지하며 저장/초기화를 차단하고 이유를 알린다. 복구 성공인 것처럼 안내하지 않는다.
- 저장 전 원문 비교로 다른 탭의 변경을 덮어쓰지 않는다. 충돌 시 이 탭을 새로고침하라는 메시지를 준다. 충돌 탭은 계속 잠금 상태다.
- 사용자가 초기화를 선택하면 현재 원문을 `ullim-city-v1-before-reset`에 백업한 뒤 초기화한다. 백업 실패·충돌이면 초기화하지 않는다. v1 마이그레이션 백업도 지우지 않는다.

## 교육·중복·과학 정확성 검토
각 시설의 관찰→비교→응용→의뢰는 같은 객관식 반복이 아니라 다른 행동으로 이어진다.
1. 진동: 여러 물체 울리기, 떨림 멈추기, 소리 나는 부분 판별, 리듬 구성.
2. 크기: 서로 다른 힘 A/B 기록, 자신의 A/B 비교, 목표 세기 신호, 세기 순서 정렬.
3. 높낮이: 자 길이 조작, 낮음→높음→중간 재현, 멜로디, 길이/세기 분리 조절.
4. 전달: 공기·물·고체 관찰, 생활 상황 연결, 센서, 전달 경로 분류.
5. 소음: 장소/사람/상황 진단, 해결 전후 비교, 해결책별 실험, 주민이 공존하는 축제 조절.

최종 5문항은 시설의 원리 적용 확인이다. 선택지 수가 적어 난도는 낮지만 증거 20개가 선행돼야 정식 완료된다. UI 파형/소리는 개념 모형이며 실제 물체의 주파수·음압 측정치가 아니다. 전달 실험을 속도 순위 학습으로 바꾸지 않았다. 배경음과 실험 소리의 분리 및 개념 영상 자막은 기존 구현을 유지한다.

## 적용한 개선 프롬프트
“11 sound의 완성된 20활동과 기존 그림·소리·지도 연출은 보존하라. 교사용 미리보기는 학생 state와 localStorage를 바꾸지 않는 별도 세션으로 만들고, 종료/새로고침 시 원래 학생 진행으로 복귀하게 하라. 잘못된 JSON과 미지원 버전은 덮어쓰거나 초기화하지 말고 보호 상태를 보여라. 두 탭 간 저장 충돌을 탐지해 오래된 탭의 덮어쓰기를 중지하라. 초기화는 브라우저 내 백업이 성공해야 수행하라. 이 동작을 단위검사 및 실제 브라우저 조작으로 검증하고, 1280×800/1920×1080/1024×768/915×412에서 홈·지도·실험 화면의 가로 넘침과 가독성을 확인하라. 커밋·배포·다른 프로젝트 변경은 금지한다.”

## 검증 기록
- `npm test`: 69/69 통과 (기존 65 + 저장 안전 4).
- `npm run check`, `npm run build`: 통과. 70 assets / 39 precached.
- `.work/series11-qa.cjs`: 실제 Chrome 독립 프로필. 시연 중 두 악기와 정답 조작, 새로고침 복귀, 손상 원문 보존, 두 탭 충돌 검사 PASS.
- 4 해상도 × 홈/지도/첫 실험 = 12화면. 가로 넘침 없음, JS pageerror 없음. 결과 `.work/series11-qa/report.json`, 화면 PNG 같은 폴더.
- 1280×800과 915×412 첫 실험 스크린샷을 직접 열어 확인했다. 짧은 화면에서는 하단 문제까지 스크롤한다.
- 처음 테스트는 설치되지 않은 Playwright 전용 Chromium 때문에 실패해 이미 설치된 Chrome으로 변경했다. 지도 시설 버튼이 시야 밖인 이동 애니메이션 상태에서는 직접 클릭 테스트가 시간 초과되어, 시연 저장 검증은 첫 활동의 명시적 초기 fixture에서 실제 DOM 조작으로 진행했다. 자동화 초기 상태 주입은 학생 완주 증거로 계산하지 않았다.
- 이미지·음향은 기존 자산으로 목적 충족하므로 새 생성 없음. 모모 가동 없음. 프로젝트 전체 오디오를 사람 귀로 청취하거나 실제 태블릿·모든 20활동을 이번에 수동 완주한 것은 아니다.
- shared graphify-out 갱신은 부모의 전체 프로젝트 작업 종료 시 일괄 처리하도록 전달한다.

## 추가 검증: 전체 20활동 UI 연속 완주
최종 검토 요청으로 기존 play-flow 검사를 맥 Chrome용으로 조정해 `.work/series11-full-flow.cjs`로 실행했다. 앞 문단의 ‘전체 완주 미검증’은 아래 자동화 UI 범위에서 해소됐다. 별도 Chrome 프로필의 빈 저장소에서 정상 학생 모드로 시작했으며 완료 상태를 주입하지 않았다.

- 홈→지도→20활동 순서대로 실행, 활동마다 증거가 정확히 하나 증가하고 admin=false인지 검사: **20/20 PASS**.
- 오답 진동 선택·리듬·신호·멜로디가 통과되지 않고 재시도 가능함을 확인.
- 3번째 활동 2라운드 후 새로고침, 진행 보존 뒤 나머지 완료.
- 소리 정렬과 감지기 배치의 포인터 드래그·클릭 확인. 슬라이더는 DOM input/change 이벤트로 조절했으므로 물리적 터치 시험이 아니다.
- 더블클릭으로 다음 라운드까지 중복 완료되지 않음.
- 시설 개념 영상5개 화면과 controls 확인. 영상 전체 청취 검증은 아니다.
- 최종5문항→정식 인증서→새로고침: 증거20개·최종 답·완료일·restored 상태 보존 PASS. 인증서 스크린샷 직접 확인.
