# 소리 탐험 학습 고도화

## 실행 계획

기준 버전은 `895442b`다. 기존 20활동과 기록 구조를 유지하며, 모든 활동의 관찰 질문·발견·다음 행동을 일치시킨다.

1. 제공 성취기준과 현재 질문·정답·소리·그림을 대조한다.
2. 각 활동에 짧은 탐구 질문과 완료 후 핵심 발견을 표시한다. 과학 낱말을 강조하고, 시설 사이의 다음 탐구 질문을 연결한다.
3. 북의 세기를 바꾼 뒤의 조작, 두 조건 조절, 상자 듣기·옮기기 안내를 현재 상태에 맞춘다. 드래그 활동에는 탭 조작 안내를 제공한다.
4. 그림이 필요한 전달 장면과 CSS 인물 표현을 검토한다. 새 이미지 생성은 내장 임시 저장 허가 또는 외장 직접 저장이 가능한 생성 경로를 확인한 뒤 진행한다.
5. 20활동 정상 완주, 오답·기록 복구, 태블릿·휴대폰 반응형, 공개 배포 파일을 확인한다.

성공 조건은 20활동에 개념과 근거가 연결되고, 다음 안내가 실제 조작 대상과 일치하며, 기존 증거·자동실험·완주 검사가 통과하는 것이다. 학습 효과와 흥미는 학생 수업 실측 대상으로 구분한다.

## 과학·표현 검토

- 떨림의 폭과 빠르기를 구분했다. 북은 같은 샘플·높낮이로 세기를 바꾸고, 자는 같은 재료·두께·힘에서 떨리는 길이를 비교한다. 높은 소리를 작게, 낮은 소리를 크게 만드는 응용이 두 개념을 연결한다.
- 파형이라는 낱말은 학생 안내에서 떨림 그림으로 풀었다. 그림과 재생 소리는 비교용 모형으로 다루며 실제 측정 Hz·dB·물질별 전달 속도를 주장하지 않는다.
- 공기·물·고체를 각각 관찰하고, 실 전화기의 마지막 문제는 실을 따라 전해지는 구간으로 명시했다. 감지기를 같은 물질에 놓는 안내는 이번 실험 조건으로 한정했다.
- 소음은 사람·시간·상황과 연결한다. 패드는 전달되는 떨림과 마찰 소리를 줄이고, 시간 변경은 독서 중의 방해를 줄인다. 안내 방송을 남기는 마지막 활동과 교사용 생활 실천 확인을 연결했다.
- 틀린 리듬에서 처음부터 다시 하라고 하던 힌트를 실제 동작에 맞췄다. 현재 구현은 맞춘 칸을 보존하며 다음 칸을 고친다.
