- 진동·크기·높낮이: 고정된 부분과 떨리는 부분을 구분한 자, 세기와 길이에 따라 달라지는 파형, 울림·쉼 신호, 소리 상자의 순서, 두 조건을 나눈 믹서.

- 노트·최종 활동: 선택한 탭의 배경색이 화면 밖 모달에서도 유지되도록 기본 강조색 확보.

검사기는 텍스트 Range와 아이콘 경계, 실제 중심점 hit-test를 사용한다. 스크롤로 도달할 수 있는 요소와 닫힌 중첩 details 내용은 오류로 세지 않는다. 고정 도구에 일시적으로 가린 조작은 가운데로 스크롤한 뒤 다시 확인한다. 매 활동의 실제 제목을 확인해 다른 화면을 중복 검사하지 않도록 했다. 초기 캡처에는 병렬 수정이 섞여 있어 변경 전 수치로 사용하지 않았다.

실제 iPad·Safari 터치와 스피커 청음은 미실측이다. 이번 결과는 설치된 Chrome의 반응형 화면과 UI 이벤트 검증 결과다.
