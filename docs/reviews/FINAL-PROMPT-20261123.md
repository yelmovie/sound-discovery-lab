## 오류·미검증 범위

- 초기 읽기용 `git status`, `git log`, `git remote`에서 macOS `xcrun`의 `/tmp/xcrun_db-*` 캐시 파일 생성 권한 경고가 있었으나 조회는 종료 코드 0으로 결과를 반환했다. 캐시 경로를 바꾸는 우회는 하지 않았다. 이후 필요한 변경 명령은 승인된 도구 권한 절차로 실행했다.
- 진단 명령 `ps -Ao pid,ppid,etime,command`는 읽기 전용 샌드박스에서 `operation not permitted`로 차단됐다. 반복·대체 조회하지 않았으며 작업 수행에는 필요하지 않았다.
- 실험·효과음 manifest의 SHA256을 추가 대조하려던 `python3` here-document는 zsh 임시 파일 생성이 `operation not permitted`로 차단되어 Python이 실행되지 않았다. 같은 대조를 우회·재시도하지 않았다. 이번 파일 내용은 바꾸지 않았고 기존 manifest 기록을 검토한 범위로 한정한다.
- 첫 브라우저 탐색은 전체 화면 영상의 숨긴 X를 눌러 타임아웃됐다. 기존 화면의 실제 ‘건너뛰기’를 따르도록 QA를 바로잡았다. 앱의 숨긴 X를 새 버튼으로 바꾸지 않았다.
- 추가 QA 중 중복 변수, 라운드 전환 입력 보호 시간, 연습 구간의 미생성 기록 접근을 수정했다. 캐릭터 그림 실패는 기존 기본 캐릭터 대체가 정상이라 기대값을 바로잡았고 앱의 대체 동작을 중복 변경하지 않았다.
