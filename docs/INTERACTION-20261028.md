# 전체 활동 조작 흐름 개선

2026-10-28. 대상: 5개 시설, 20개 활동과 마지막 코어 복구.

## 플레이 변화

- 활동의 관찰·청음·정답 조건을 모두 충족하면 증거를 즉시 기록한다. 발견 내용과 진행 수를 활동 화면에 표시하며, 반복되던 증거 확인 → 완료 팝업 → 다음 단계를 다음 활동 버튼 하나로 줄였다.
- 시설의 네 활동을 마치면 복구 영상과 배지를 볼 수 있다. 영상 화면에서 바로 다음 시설로 이어지며 지도는 활동 화면에서 언제든 열 수 있다.
- 떨리는 부분 찾기, 리듬, 멜로디, 상자 정렬, 감지기 배치, 전달 경로 연결, 해결책의 전후 비교는 마지막 의미 있는 조작으로 판정한다. 믹서는 조절 후 실제 연주 동작으로 주문을 제출한다.
- 북을 두 번 다른 세기로 치면 A/B에 자동 기록한다. 같은 세기를 반복하면 비교 증거를 만들지 않는다. 다시 치면 B가 바뀌며 A/B 교체 버튼도 제공한다.
- 자의 길이를 바꾸면 바로 튕겨 관찰 기록을 남긴다. 같은 길이 다시 듣기를 별도로 제공한다.
- 소리 상자를 누르면 듣기와 선택을 함께 수행한다. 드래그로 놓을 때도 청음하며, 이미 놓인 상자를 다른 칸으로 옮기면 자리를 교환한다.
- 틀린 리듬·멜로디는 다음 입력부터 새 연주를 시작한다. 완료 효과음으로 마지막 실험음을 덮어쓰지 않으며 리듬 마지막 울림은 짧게 마무리한다.
- 생활 속 전달 문제는 물질을 고르면 검증하고 다음 미완료 상황으로 이어진다. 축제는 주민의 마지막 조건을 충족하는 조작에서 완료된다.
- 마지막 다섯 문항은 답 선택 뒤 다음 문항으로 이어진다. 코어 복구 시 틀린 문항이 있으면 해당 원리부터 다시 확인할 수 있다.

## 상태·입력 보호

학습 조건과 증거 20개·최종 정답 5개의 완료 기준은 기존 검사를 사용한다. 새 저장 버전이나 서버, 학생 정보 수집은 추가하지 않았다. 기존 49개 에셋을 사용하며 새 생성 에셋과 외부 의존성은 없다.

자동 기록은 활동별 의미값을 비교하므로 준비 중인 슬라이더 값이나 안내 문구만으로 기존 증거를 다시 쓰지 않는다. 오답으로 재실험할 때는 이전 증거를 보존하며, A/B를 다시 기록하면 비교 활동은 새 소리를 요구한다. 저장 실패 경고는 계속 제공한다.

라운드 토큰과 짧은 전환 입력 보호로 연타·늦은 드래그가 다음 문제를 해결하지 못하게 한다. 드래그는 시작한 활동과 라운드가 같을 때만 반영한다. 화면 이동·모달 열기·탭 숨김 시 마지막 문제의 자동진행 예약을 취소한다. 동작 줄이기 설정도 유지한다.

## 변경 위치

- `src/app.js`, `src/progress.js`: 자동 증거 기록, 활동 이동, 직접 조작, 최종 문항 진행.
- `src/challenges.js`, `src/manipulations.js`: 직접 판정, 재연주, 드래그와 라운드 보호.
- `src/companion.js`, `src/data.js`, `src/experience.css`: 조작 안내, 힌트 대상, 진행·성공 표시.
- `tests/progress.test.mjs`, `tests/challenge-flow.test.mjs`, `tests/model.test.mjs`: 새 흐름과 기존 저장·학습 조건 회귀 검사.
- `package.json`, `scripts/build.mjs`: 새 모듈의 구문 검사 포함.

## 검증

- 구문 검사, 자동 테스트 56개, 프로덕션 빌드 통과.
- 격리된 새 브라우저에서 관리자 해금이나 증거 주입 없이 20개 활동을 실제 UI로 해결했다. 복구 영상 5편 → 마지막 5문항 → 정식 인증서 → 새로고침 후 증거 20개와 완료 유지까지 확인했다.
- 틀린 답, 틀린 연주 직후 재도전, 활동 중간 새로고침, 상자·감지기 포인터 드래그, 연결 버튼 연타를 확인했다.
- 1024×768, 1280×800, 1920×1080의 활동 시작과 1280×800의 완료 상태 총 80화면을 측정했다. 화면 밖으로 잘린 조작 버튼, 가로 이탈, 브라우저 런타임 오류, 실패한 HTTP 요청 모두 0건이다.
- 실행 기록: `.work/play-flow.cjs`, `.work/play-flow/report.json`, 해당 폴더 스크린샷.
- 별도 검증용 완료 상태로 1024×768·1280×720에서 20활동의 완료 화면 40건을 추가 측정했다. 모든 다음 버튼의 실제 포인터 접근을 확인했고 패널 내부 스크롤과 가로 이탈이 없었다. 높이 720px에서 관찰창과 자 실험대 여백을 줄여 4~5px의 불필요한 스크롤을 제거했다.
- A/B 완료 후 준비 세기만 바꾸기, 전환 직후 슬라이더 되돌리기, 설정·홈 이동 때 최종 문항 자동진행 취소, 키보드 Enter/Space, 터치 탭, 저장 실패 경고와 메모리 상태로 계속 진행하기를 브라우저에서 확인했다. 이 추가 검사는 검증용 상태를 사용했으며 정상 전체 플레이 결과와 구분한다. 기록: `.work/edge-flow.cjs`, `.work/edge-flow/report.json`.

실제 태블릿·전자칠판, 스피커 실청과 교실 환경은 이번 데스크톱 검증에 포함하지 않았다. 외부 배포는 수행하지 않았다. 상위 지침의 graphify 갱신은 도구가 설치되어 있지 않고 기존 그래프도 없어 실행할 수 없었다.
