# 기능 아이콘 점검·프롬프트

2026-10-22. 홈·이전·스피커·설정·재생·확인 등 단순 기능 아이콘은 프로젝트 SVG를 사용한다. 운영체제별 이모지나 새 래스터 아이콘 생성으로 교체하지 않는다. 체크 표시와 진행 숫자는 상태 텍스트다.

| 위치 | 용도 | 처리 | 규격 |
|---|---|---|---|
| src/app.js 공통 HUD | 홈·이전·소리·설정 | SVG + 접근 가능한 이름 | 아이콘 24px 내외, 터치 48×48px 이상 |
| 활동 버튼·피드백 | 재생·확인·소리 원리 | 공통 SVG와 텍스트 | 버튼 터치 48px 이상 |
| 지도·성취 | 시설 표시·복구 상태 | 지도 이미지·SVG·텍스트 병용 | 색만으로 상태를 구분하지 않음 |

새 이미지 생성 프롬프트 대상은 없다. 투명 소품과 보행 그림은 PROP-PROMPTS.md 및 생성 manifest를 참조한다. 실제 브라우저 가독성·터치 검증 결과는 최종점검 보고서에서 따로 기록한다.
