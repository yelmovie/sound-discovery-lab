# 울림도시 v2.1 변경·검증 기록

2026-10-22, 대상: 초등학생 태블릿 조작 및 전자칠판 수업.

## 적용한 내용

시설 5곳에서 관찰·비교·응용·의뢰를 마치면 해당 시설의 **16초 개념 영상**으로 연결한다. 4초씩 네 장면으로 원인·변화·비교·결론을 보여 주며 마지막 장면은 결론을 유지한다. 마지막 자막은 브라우저 재생 버튼에 가리지 않도록 하단 80px의 제어 영역 위에 배치했다. 분석에 필요한 정면 고정 구도로 물체와 파형 또는 전달 경로를 함께 보여 준다. 소리 크기 비교의 주파수는 같게 유지한다. 전달 영상은 물질별 속도나 음량의 우열을 표현하지 않는다.

| 시설 | 영상 | 직접 조작하며 확인하는 것 |
|---|---|---|
| 진동 연구소 | vibration.mp4 | 물체 울리기, 떨림 중 멈추기, 떨리는 부분 찾기, 울림·쉼 연주 |
| 볼륨 경기장 | volume.mp4 | 북을 아래로 쓸어 세기 바꾸기, 내 A/B 비교, 소리 상자 드래그 |
| 조율 공방 | pitch.mp4 | 자의 길이 슬라이더, 길이에 따른 파형, 서로 다른 길이의 건반, 길이·세기 분리 |
| 전달 네트워크 | travel.mp4 | 독립된 세 전달 실험, 감지기 배치, 생활 속 소리 길 연결 |
| 소음 관리센터 | care.mp4 | 현장 진단, 해결 도구 드래그와 전후 비교, 음악·안내 믹서 및 주민 반응 |

동행 새를 **삐오**로 이름 붙이고 새 안내 일러스트와 20개 활동의 3단계 힌트를 연결했다. 다음 조작 대상을 강조하고, 실제 조건을 충족하면 증거 확인 버튼을 강조한다. 지도 동행 경로와 사람 탐험가의 기존 보행 애니메이션은 재사용했다.

한 화면에 하나의 주요 조작과 증거 확인을 배치한다. 중복 선택 버튼과 일반 안내문을 줄이고 노트는 시설당 네 기록만 보여 준다. 마지막 복구는 다섯 원리를 한 문제씩 보여 준다. 인증서의 긴 반복 설명은 다섯 영상 다시 보기로 바꿨다. 설정은 소리 스위치와 도움말을 묶고, 설명·교사용 상세 자료는 펼쳐 본다.

## 검증 결과

- 구문 검사, 기존 학습·저장·오디오·지도 테스트와 추가 영상·HTTP Range·효과음 취소 테스트 **38개**, 빌드 통과.
- 기존 진행 기록이 있는 `127.0.0.1`과 분리한 `localhost`에서 UI로 20개 활동을 해결하고 최종 복구·정식 인증서까지 진행했다. 배지와 영상 5종의 연결을 확인했다.
- 1024×768, 1280×800, 1920×1080에서 활동 **60화면**을 실측했다. 활동 본문·보조 패널의 불필요한 스크롤과 가로 이탈 없음. `layout-checks-v2.1.json`에 기록했다.
- 같은 세 크기에서 설정·동기 안내·초기화 확인·노트·영상·증거 보상 **18팝업**의 중앙 정렬 오차 0px, 기본 내용의 내부 스크롤 0px. 펼친 도움말·영상 원문은 사용자 선택에 따라 스크롤한다. `modal-layout-v2.1.json`에 기록했다.
- 마지막 다섯 질문 **15화면**, 홈·지도·최종 복구·인증서 **12화면**을 실측했다. 작은 지도에서 시야 밖 두 건물은 기존 카메라 이동을 따라 나타나는 의도된 동작이다. `global-layout-v2.1.json`에 기록했다.
- 실제 포인터 드래그로 상자·감지기·소리 길·해결 도구를 조작했다. 드래그 직후 확인 버튼이 무시되던 문제를 수정했다. 키보드로 길이·세기·축제 슬라이더를 조절하고 완료를 확인했다.
- 모든 영상은 H.264/AAC, 960×540, 24fps, 16초. 전체 동영상 약 2.1MB. 자막 MIME, MP4 범위 요청과 탐색, 로컬 효과음 MIME을 검사했다. `media-checks-v2.1.json`에 기록했다.
- 효과음 설정을 끄면 영상이 음소거로 열리는 것을 확인했다. 영상에서는 배경 음악을 멈추고 닫기·이동·탭 숨김 때 재생을 정리한다. 최종 브라우저 콘솔 오류 없음.

## 변경 위치와 재생성

- `src/app.js`, `experience.css`: 화면·팝업·노트·최종 복구·인증서 흐름.
- `src/concepts.js`, `media/concepts/`, `scripts/render-concepts.py`: 영상·자막·포스터 및 재생성.
- `src/companion.js`, `image/generated/pio-guide.svg`: 삐오와 힌트.
- `src/manipulations.js`, `challenges.js`: 포인터 조작과 실시간 피드백.
- `src/audio.js`, `media/audio/`: Kenney CC0 효과음. 출처와 원본 이용 조건은 CREDITS.md 및 포함된 License.txt 참조.
- `scripts/server.mjs`, `build.mjs`, `data.js`: 미디어 MIME·Range·오프라인 빌드 포함.

브라우저 검증은 데스크톱의 지정 해상도에서 수행했다. 실제 태블릿·전자칠판의 터치 감도, 교실 스피커 실청, 실제 학습 효과는 현장에서 확인할 항목이다. 음성 해설은 포함하지 않았다. 인터넷에 새로 배포하지 않았다.
