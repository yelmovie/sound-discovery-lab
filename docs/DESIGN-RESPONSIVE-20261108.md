# 활동 실험대 반응형·시각 설계

후속 요청으로 실험 화면의 스크롤 허용 기준을 변경했다. 현재 구현 기준은 [실험 한 화면·자동실험](SINGLE-SCREEN-PLAN-20261108.md)이며, 아래 내용은 이전 배치의 기록이다.

적용 범위: 5개 시설의 20개 활동과 공통 안내·최종 화면. 기존 저장·정답·해금 규칙을 유지한다.

- 그림, 조작 설명, 상태를 각각 실제 레이아웃 행으로 나눈다. 그림 100% 높이와 설명이 같은 고정 높이를 경쟁하지 않게 한다.
- 1100px 이하 또는 높이 620px 이하에서는 상단 도구 모음 아래의 활동 영역만 세로로 스크롤한다. 도구 모음과 본문이 겹치지 않게 영역을 분리하고, 좁은 화면에서도 글자 크기를 유지한다. 넓은 화면은 실험대와 탐험 친구를 나란히 두고, 긴 실험대는 내부에서 스크롤한다.
- 공통 글자 크기는 기존 `--read`, `--read-small`, 간격은 `--space`, 모서리는 `--panel-radius`를 따른다. 아이콘은 축소되지 않는 칸을 가지며 글자는 줄바꿈한다. 주요 터치 영역은 48px 이상을 유지한다.
- 시설 색은 진동 청록, 크기 황토, 높낮이 보라, 전달 초록, 배려 장미색의 보조 색으로 구분한다. 상태는 색과 체크·테두리·문구를 함께 사용한다.
- 진동: 물체와 조작 설명을 분리하고 관찰한 물체/떨림을 표시한다. 크기: A/B에 입력 세기를 기록하고 같은 조건의 파형을 나란히 비교한다.
- 높낮이: 고정한 부분과 자유롭게 떨리는 부분을 분리한 자와 길이 조절을 연결한다. 크기와 높낮이의 두 조절 축을 구분한다.
- 전달: 소리 나는 곳 → 전달 물질 → 듣는 곳을 순서대로 표현한다. 물질별 속도·음량의 순위는 표시하지 않는다.
- 배려: 상황과 영향을 받는 사람, 적용 전후를 분리하고 축제 주민의 요청 충족 여부를 표시한다.
- 파형은 실제 계측값이 아닌 떨림·소리 비교 모형이다. 진폭과 촘촘함을 구분하며 측정 단위를 만들지 않는다. 반복 장식 애니메이션은 추가하지 않고 동작 줄이기를 지원한다.
- 검증: 전 활동의 실제 경로를 확인한 브라우저 스윕, 텍스트 범위와 버튼 가림 검사, 대표 화면 시각 확인, 기존 기능 테스트·빌드. 자동화로 확인하지 못한 실물 태블릿·스피커는 별도로 기록한다.

파일 소유: 공통 레이아웃·기존 활동(root), 의뢰 UI(challenge_design), 자·파형(experiment_visuals), 브라우저 검사(responsive_qa). 공용 CSS와 브라우저는 각각 한 담당자만 수정·실행한다.
