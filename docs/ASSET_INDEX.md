## 이번 대화에서 확인한 화면 원칙

- 학습 10장(5스테이지 × 2장)과 메인·스테이지 지도·마무리 공통 화면을 별도로 둔다.
- 메인 다음 자연 속 스테이지 지도에만 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG 표현과 캐릭터 이동을 적용한다.
- 장소에 들어가면 기존 스타일의 2D 학습 화면으로 전환한다.
- 모든 페이지 좌측 상단: 홈, 이전. 우측 상단: 소리, 설정.
- 설정에 관리자 전체 해금 스위치 하나를 둔다. 전체 스테이지와 마무리 접근을 한 번에 열며, 실제 학습 완료 기록을 조작하지 않는 방향을 제안한다.

## 추가 제작이 필요한 자료

- 자연 속 픽셀 스테이지 지도, 이동 가능한 길과 앞뒤 가림 레이어, 캐릭터 걷기 프레임.
- 개별 캐릭터와 실험 도구의 투명 스프라이트.
- 학습 소리·효과음·배경음. 현재 오디오 파일 없음.
- 3D 모델. 현재 모델 파일 없음. [3D 원본 이미지 목록과 프롬프트](https://chatgpt.com/space/page_e5c729a999bc8191a58096624d8e5603)에 우선 후보 4종과 확장 후보 6종, 공통 생성 기준 및 시점별 프롬프트를 정리했다.
- 공유 대화에 언급된 과거 PRD·TRD·심화 설계서와 원본 수업 자료는 현재 로컬 폴더에 없다. 대화의 요약을 확인했으며, 해당 첨부 문서 원문을 확보한 것으로 간주하지 않는다.
