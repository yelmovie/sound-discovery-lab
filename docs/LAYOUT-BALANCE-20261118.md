## 중복 조작 버튼 전수 점검

화면마다 보이는 조작 요소(글자·aria-label·data-action)를 뽑아 같은 일을 하는 것을 찾았다.

| 화면 | 중복 | 처리 |
|---|---|---|
| 「노트와 개념 영상」 팝업 | 위 X + 아래 「닫기」 | 아래 「닫기」 숨김(X는 첫 포커스·Esc와 같은 자리) |
| 「내 증거 노트」 팝업 | 위 X + 아래 「닫기」 | 아래 「닫기」 숨김 |
| 이야기·삐오 안내(인물 대화 카드) | 위 X + 아래 「닫기」 | 아래 「닫기」 숨김. 목소리 다시 듣기·「탐험하러 가기」는 그대로 |
| 마지막 미션 | 「이전 원리」 = 위 원리 알약(바로 앞 원리 포함)과 같은 일 | 「이전 원리」 숨김 |
| 결과(교사 미리보기) | 「증거 모으러 가기」 + 「지도 둘러보기」 둘 다 지도로 | 「지도 둘러보기」 숨김(정식 인증서 화면에서는 유일한 지도 버튼이라 그대로) |

없앤 중복: 5종(팝업 3종의 「닫기」, 「이전 원리」, 미리보기 「지도 둘러보기」). 진행 경로는 모두 남아 있다(X·Esc·원리 알약·주 버튼).

남긴 것과 이유:

- **설정 팝업** X + 「닫기」: 아래 「탐험 기록 초기화」와 짝인 확인형 창이고, 다른 세션의 QA 스크립트(`qa-run-stage.mjs`는 아래 「닫기」, `qa-responsive`·`qa-single-screen`은 위 X)가 둘 다 누른다. 보수적으로 그대로 둠.
- **초기화 확인** X + 「취소」: 지우기 확인 창은 명시적인 취소를 남긴다.
- **개념 영상 창**: 자막 세션이 작업 중인 `concept-focus.css` 범위라 건드리지 않음.
- **활동 2 「떨림을 멈추면」**: 소리굽쇠 그림(누르면 울리기/잡기) + 「소리굽쇠 울리기」·「손으로 눌러 멈추기」 버튼이 같은 일을 한다. 그러나 아래 지시문(`app.js` `lessonCue`)이 「손으로 눌러 멈추기를 눌러」처럼 버튼 이름을 부르므로, 버튼을 숨기면 지시와 화면 글자가 어긋난다. `app.js` 문구 수정이 필요해 이번에는 **제안만**: 지시문을 「소리굽쇠를 눌러 잡아 봐」로 바꾸고 버튼 줄을 숨긴다.
- **지도** 시설 표지 + 오른쪽 아래 「○○로 가기」: 표지는 아무 시설이나 고르는 직접 조작, 주 버튼은 다음 목적지 한 곳(3초 규칙의 주 버튼)이라 유지.
- **활동 화면 아래 띠**(자동재생·속도·힌트·노트): 서로 다른 일. 주 버튼(다음 활동/시설 복구)은 완료 때만 오른쪽 아래 한 곳.
