# 울림도시 대작전 — PRD

갱신일: 2026-10-22. 5개 시설 × 관찰·비교·응용·의뢰 4활동, 총 20개 활동으로 확장한다. 기존 10개 실험과 제공 이미지를 보존한다.

## 목표와 흐름

소리 코어가 멈춘 숲 마을에서 학생 탐험가와 파란 울림새가 소리를 조사한다. 직접 소리를 내고 조건을 바꾸며 모은 증거가 시설 복구와 주민의 반응으로 이어진다. 빠른 클릭이나 첫 정답 대신 관찰·비교·수정에 보상을 준다.

메인 → 길을 걷는 2.5D 픽셀 RPG 지도 → 시설 안 2D 활동 → 증거 노트·시설 복구 → 마지막 공연 해결 → 결과·인증서. 지도는 생성한 마을 그림, 길 그래프, 탐험가·동행 새 보행 스프라이트, 복구 불빛을 분리한다. 그림 속 글자나 버튼을 클릭하는 모형으로 만들지 않는다.

## 학습 활동 20개

| 번호 | 시설·단계 | 조작·완료 조건 | 남는 증거 |
|---:|---|---|---|
| 1 | 진동·관찰 | 서로 다른 물체 2개 이상 울리고 공통점 설명 | 관찰 물체와 떨림 관계 |
| 2 | 진동·비교 | 소리굽쇠 울리기 → 소리가 나는 동안 눌러 멈추기 → 전후 설명 | 울림·멈춤 기록 |
| 3 | 진동·응용 | 북·고무줄·자·소리굽쇠를 각각 울려 떨리는 부분 찾기 | 물체별 위치 4개 |
| 4 | 진동·의뢰 | 울리기와 눌러 멈추기로 길이가 다른 신호 3개 만들기 | 울림·쉼 순서 |

| 13 | 전달·관찰 | 공기·물·고체의 독립 실험 모두 확인 | 세 물질의 전달 여부 |
| 14 | 전달·비교 | 목소리·물속 돌·탁자 두드림 상황을 선택 후 검증 | 새 상황 3개 |
| 15 | 전달·응용 | 소리원과 감지기를 관찰할 같은 물질에 놓기 | 공기·물·고체 배치 |

한 시설의 네 활동을 모두 끝내면 해당 시설과 코어 링이 복구된다. 순서대로 떨림 탐정·크기 조절사·멜로디 장인·소리 길잡이·소리 배려가의 성취를 얻는다. 의뢰의 각 소과제는 즉시 피드백과 진행 표시를 주며, 재도전에서 다시 소리를 만들고 조합할 수 있다. 미완료 의뢰는 증거로 기록하지 않는다.

## 학습·동기 설계

- 메인과 지도에서 “증거를 모아 소리 코어와 마을을 되살린다”는 목적을 먼저 제시한다. 시설의 문제 → 직접 실험 → 증거 → 주민 변화 → 다음 시설로 이어진다.
- 관찰 결과가 다음 활동에 쓰인다. 크기 비교는 실제 A/B, 소음 해결은 실제 진단을 참조한다. 관리자 접근으로 선행 기록이 없으면 원래 활동으로 안내한다.
- 한 활동 안에서도 여러 물체·조건·상황을 다룬다. 선택만 반복하지 않고 소리 제어·순서 만들기·배치·조건 조합·비교를 섞는다. 잘못 고르면 구체적인 관찰 단서와 재시도를 제공한다.
- 진동, 소리의 크기와 높낮이, 소리 전달, 일상 속 소음 배려를 다룬다. 아래 성취기준과 활동을 연결하며 학생 현장 검증과 실제 생활 실천 평가는 별도로 다룬다.

## 교육과정 연계

공식 교육과정 자료의 다음 원문과 연계한 탐구 보조 활동이다. 이 게임만으로 성취기준 전체를 달성했다고 판단하지 않으며 수업·토론·후속 평가와 함께 활용한다.

| 성취기준 원문 | 활동 대응 | 수업에서 보완할 부분 |
|---|---|---|
| [4과07-01] 여러 가지 물체를 이용하여 소리를 내보고, 소리가 나는 물체는 떨림이 있음을 설명할 수 있다. | 1~4: 물체 관찰·떨림 멈추기·부분 찾기·울림/쉼 신호 | 실제 물체를 이용한 관찰과 학생의 근거 설명 |

## 공통 UI·설정·저장

모든 화면에 홈·이전·소리·설정 아이콘을 둔다. 터치 대상 48px 이상, 핵심 안내 18px 이상, 한글 어절 줄바꿈, 키보드 초점을 적용한다. 설정은 배경 음악·효과음 스위치와 배경 음악 음량, 시작 이야기 다시 보기, 앱 정보·배움과 보상, 학생·교사 가이드, 저작권, 초기화·닫기 순서다.

관리자 전체 해금 버튼 하나는 모든 화면의 접근만 연다. 증거·보상·인증서 기록을 만들지 않는다. 끄면 학생 원래 진행에 맞게 접근을 다시 검사한다. 정식 완료는 증거 20개와 마지막 공연 5문항을 모두 충족해야 한다. 미완료 상태의 관리자 결과는 미리보기로 구분한다.

관찰·답안·의뢰 진행·증거·설정·마지막 화면을 브라우저에 저장한다. v1의 기존 10개 증거는 새 위치로 옮기고 추가 활동은 미완료로 둔다. 초기화는 지울 항목을 설명한 확인 단계를 거치며 소리 설정은 남긴다. 학생 이름·학번·연락처를 입력받지 않는다.

## 시각·과학·범위

기존 장소 배경 10개·캐릭터 시트와 새 지도·보행 3개·소품 10개를 사용한다. 원본은 보존한다. 지도만 2.5D 픽셀 RPG이며 실내는 2D다. 생성된 소품은 추후 3D 모델 전환을 위한 기준 그림이다. 실제 3D 모델·WebGL 도입은 이번 구현 범위가 아니다.

소리는 Web Audio 합성 모델이며 실제 물체 녹음이 아니다. 파형은 정성적 표현이며 dB 계측값이 아니다. 같은 자의 길이 비교에서 재료·두께·힘을 고정한다. 전달 실험은 전달 여부를 다루며 물질별 실제 속도·음량 순위를 가르치지 않는다. 시간 변경은 현재 독서 시간의 방해를 줄인 것으로 설명한다. 실험 중에는 배경 음악을 끄고 청음에 집중한다.

## 수용 기준

정상 경로로 20개 활동과 마지막 공연을 끝낼 수 있어야 한다. 오답 수정·증거 저장·리로드·구버전 이관·관리자와 완료 분리를 검사한다. 생성 이미지와 지도 이동·동행 캐릭터가 실제 화면에 연결되어야 한다. 1280×800과 1024×768에서 핵심 안내·조작·설정 닫기가 접근 가능해야 한다. 실제 수행한 검사와 미검증 항목은 별도 검증 보고서에 기록한다. 외부 배포·계정·서버 DB·추가 유료 생성은 포함하지 않는다.
