# 개념영상 「삐오의 소리 노트」 리뷰 (2026-11-09)

5편(떨림·크기·높낮이·전달·배려), 각 16초 = 4장면 × 4초. 앱 자막 강조(`Math.floor(currentTime/4)`)·VTT·전사 목록의 문장과 경계를 그대로 쓴다(`tests/concept-films.test.mjs`).

## 만든 방식
- `films.data.mjs`: 제목·자막은 `src/concepts.js`에서 그대로 가져온다. 색은 앱 토큰(`src/style.css :root`).
- `build-films.mjs`: 편마다 `films/<id>/index.html` + `assets/`(이미지 복사, 효과음 가공)를 쓴다. 공용 부품: 노트 바탕·머리글·자막 띠·이름표·파형 창·말렛 치기·감쇠 진동·삐오 반응.
- `render-films.mjs`: `hyperframes render --quality delivery`(1920×1080) → 앱용 1280×720 H.264/AAC faststart + 결론 장면 포스터(15.7초).
- 그림: 게임에 있는 소품·개념 그림·삐오 SVG만 사용. 손·파형·소리 호·이름표만 코드로 그렸다. 새 이미지 생성 없음.

## 과학적으로 맞춘 소리 (측정값)
| 편 | 장면 | 소리 | 측정(0.5초 창 RMS) |
|---|---|---|---|
| 떨림 | 1·2 | 소리굽쇠 녹음(440 Hz) 두 번 울림 | −9 → −16 dB로 서서히 작아짐 |
| 떨림 | 3 | 손으로 잡는 순간(9.0초) 0.3초 페이드 | 9.5초부터 무음(게임 정답 "작아지다가 멈췄어"와 일치) |
| 크기 | 1·2·3 | 같은 북 녹음, 음량만 0.22 vs 1.0 | 약하게 −28 dB / 세게 −15 dB (13 dB 차) |
| 높낮이 | 2·3·4 | 같은 자 녹음, 긴 자 ×1 / 짧은 자 ×2.5 재생 속도(게임 260→650 Hz와 같은 비율) | 음원 길이 1.100초 → 0.443초(비율 2.48) |
| 전달 | 1·2·3 | 공기=북, 물=소리굽쇠(게임 `transferSound`와 같음), 고체=나무 두드림 | 세 구간 모두 소리 있음 |
| 배려 | 1·2 | 북 0.85 → 음량 줄인 북 0.25, 의자 두드림 → 패드 뒤 저역 통과+작게 | 줄인 뒤 소리 작아짐 |

- 자 녹음은 날카로운 클릭 뒤 울림이 작아 두 길이 모두 **같은** 압축을 걸었다(같은 힘 = 같은 처리). 최대 −2.0 dBFS, 클리핑 없음.
- 음악·내레이션 없음. 효과음은 그림이 움직인 다음 프레임에 놓았다.
- 소리는 **측정만 했고 사람 귀로 듣지 않았다.** 교실 스피커 청음은 남은 확인.

## 확인한 것
- `hyperframes check --json`: 5편 모두 `ok:true`, 오류 0.
- `hyperframes snapshot`으로 장면마다 프레임을 보고 겹침을 고쳤다: 말렛이 파형 창을 덮던 것, 삐오 말풍선이 파형·이름표를 덮던 것(크기·높낮이·전달은 오른쪽 위로), 패드가 처음부터 붙어 있던 것(패드 부분을 가렸다가 붙일 때 드러냄), 고체 펄스가 탁자 색에 묻히던 것.

## 일부러 둔 경고
- `font_face_local_only`: 글꼴은 앱과 같은 Apple SD Gothic Neo를 `local()`로 쓴다. 이 맥에서 렌더할 때만 같은 모양이다(클라우드 렌더 안 함). 저장소에 글꼴 파일을 넣지 않기 위한 선택.
- `container_overflow`(파형): 창 안에서 흐르는 파형이라 의도된 넘침.
- `nested_structure_needs_subcomposition`: 편당 한 파일로 데이터에서 생성하는 구조라 Studio 행 구분보다 재생성 쉬움을 택했다.
- `duplicate_media_discovery_risk`: 소리굽쇠를 갈래(떨리는 부분)와 손잡이로 나눠 같은 그림을 두 번 씀.

## 가장 약한 장면과 다음에 할 일
- 배려 3장면(시계·운동장)은 그림 자체가 움직이지 않아 화살표·이름표만 움직인다. 시곗바늘을 코드로 그리면 더 좋다.
- 떨림 편의 손은 코드로 그린 단순한 손이라 게임 그림체보다 평면적이다.
- 만들지 않은 안: 게임 화면 캡처를 그대로 재생하는 데모형, 삐오 내레이션형(게임 내레이션과 겹쳐 제외).
