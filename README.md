# 울림도시 대작전

초등 과학 「소리의 성질」을 탐구하는 로컬 웹게임 MVP. **5개 시설 × 관찰·비교·응용·의뢰 = 20개 활동**을 마치고 소리 코어를 복구한다. 스테이지 선택 지도는 2.5D 픽셀 RPG, 시설 안 활동은 2D다.

## 한 화면 실험 · 자동실험 (2026-11-08)

20개 활동은 제목·단계, 큰 실험대, 하단 조작줄로 구성한다. 현재 해야 할 조작이나 선택지 묶음 하나를 강조하고, 안내는 하단 한 곳에 표시한다. 노트·개념 영상·지도와 교사용 빠른 이동은 책 모양 메뉴에 모았다.

자동실험은 재생 버튼으로 시작하며 0.5·1·1.5·2배 속도, 일시정지·이어 재생·정지를 지원한다. 속도는 단계 간격만 바꾸고 소리의 높낮이를 바꾸지 않는다. 관찰·청음·길이와 세기 비교를 진행한 뒤 정답 선택·배치·목표 연주에서는 학생을 기다린다. 화면 이동·수동 조작·팝업·탭 숨김에서 자동실험을 취소한다.

설계와 검증 범위는 [한 화면 구현 기준](docs/SINGLE-SCREEN-PLAN-20261108.md)과 [검증 기록](docs/reviews/SINGLE-SCREEN-20261108.md)에 기록한다.

## 바로 실행

Node.js 20 이상이 필요하며 외부 패키지 설치는 없다.

프로젝트 폴더에서 실행한다. macOS의 작업·캐시·임시 경로는 외장 SSD를 사용한다.

```sh
npm start
```

Windows PowerShell에서는 `npm.cmd start`를 사용한다.

브라우저에서 **http://127.0.0.1:4173** 을 연다. 종료는 터미널의 Ctrl+C다. Start-Ullim.ps1로도 실행할 수 있다. 포트가 사용 중이면 기존 서버를 확인하거나 `$env:PORT='4174'`로 다른 포트를 지정한다. 서버는 이 컴퓨터의 127.0.0.1에서만 열린다. 태블릿에서는 위 운영 사이트에 접속한다.

## 검증·빌드

```sh
npm run check
npm test
npm run build
npm run preview
```

빌드는 dist/에 실행 파일과 참조 에셋 **103개**(이미지·영상·자막·효과음·출처 기록)와 공유 이미지·아이콘·`sw.js`·`manifest.webmanifest`를 복사하고, `dist/sw.js`에 캐시 버전과 미리 저장할 파일 54개를 기록한다. 2026-10-28에 핵심 개념 그림 13개 약 0.78MB와 CC0 녹음 효과음 6개 약 80KB를 추가하고 개념 영상 5편을 다시 만들었다. preview와 start는 기본 포트가 같으므로 동시에 켜지 않는다. file:// 더블클릭 실행은 지원하지 않는다. 모든 실행 의존성이 Node·브라우저 내장이므로 exFAT의 심볼릭 링크·하드링크·패키지 설치가 필요 없다.

## 플레이

2026-10-28: 전체 20활동의 반복 확인을 줄였다. 조건을 충족하면 증거가 자동으로 기록되고, 발견을 읽은 뒤 **다음 활동** 한 번으로 이어진다. 시설 복구 영상에서도 바로 다음 시설로 이동한다. 북 타격 A/B 자동 기록, 길이 변경 즉시 연주, 배치·연결 즉시 판정, 오답 연주 바로 재시작을 적용했다. 변경·검증 내용은 [전체 활동 조작 흐름 개선](docs/INTERACTION-20261028.md)을 참고한다.

탐험 시작 → 지도에서 진동 연구소 선택 → 길을 따라 탐험가와 울림새 이동 → 물체 조작·비교 → 증거 기록. 방향키/WASD, 화면 방향 버튼, 목적지 선택으로 이동할 수 있다. 시설마다 네 활동을 끝내면 불빛과 코어 링이 복구된다.

떨리는 부분 찾기·울림과 쉼의 신호, 크기 조절·소리 상자 정렬, 멜로디 연주·길이와 세기 조합, 감지기 배치·생활 속 전달 경로, 소음 해결·축제의 소리 조절을 거친다. 소과제 진행은 자동 저장되고 오답은 관찰 단서를 보고 바꿔 재시도할 수 있다. 증거 20개와 마지막 공연 문제 5개를 해결하면 정식 완료다. 인증서는 결과 화면에서 인쇄하거나 운영체제의 PDF 저장을 사용한다.

상단 홈·이전·소리·설정은 모든 화면에서 제공한다. 증거 노트에서 실험 조건을 다시 볼 수 있다. 설정의 **모든 단계 한 번에 열기** 버튼 하나로 관리자 미리보기를 켜고 끈다. 접근만 열며 증거·보상·완료는 채우지 않는다. 선행 기록이 필요한 비교 화면은 원래 활동으로 안내한다. 미완료 상태의 결과는 미리보기로 구분한다.

## 저장·오디오

- 이 브라우저의 ullim-city-v1 localStorage에 버전 2 형식으로 실험·의뢰·증거·설정·마지막 화면을 저장한다. 학생 이름·학번·연락처를 수집하지 않는다.
- 구버전 기록은 기존 실험의 새 위치로 옮기며 추가 활동은 미완료다. 최초 이관 시 원본을 별도 백업 키에 보존한다. 구버전 완료만으로 새 인증서를 발급하지 않는다.
- 저장은 주소별로 분리된다. localhost와 127.0.0.1, 포트·브라우저가 달라지면 기록도 다르다. 시크릿 창이나 브라우저 데이터 삭제 시 기록이 사라질 수 있다.
- 설정에서 기록 초기화 → 확인으로 이 게임의 기록만 초기화한다. 배경 음악·효과음·음량·음소거 설정은 남긴다.
- 최초 클릭 후 북·자·고무줄·소리굽쇠의 CC0 녹음과 화면 효과음이 재생된다. 배치음은 나무 타격, 복구 보상은 칼림바 녹음으로 구성했다. 배경 음악과 효과음을 따로 켜고, 슬라이더로 배경 음악 크기만 조절한다. 상단 소리 버튼은 둘을 한 번에 음소거한다.
- 배경 음악은 메인·지도·결과에서만 재생한다. 활동의 소리를 비교할 때는 섞지 않는다. 재생 교체·화면 이동·탭 숨김 때 소리를 정리한다. 음원 파일은 로컬에 포함하며 실행 중 외부 음원 접속·마이크 권한은 필요 없다.
- 북의 크기는 같은 녹음의 음량만 바꾸고, 자의 높낮이는 같은 녹음의 상대 재생 속도로 조절한다. 코드의 주파수 제어값과 파형은 실제 측정 Hz/dB가 아니다. 전달 실험은 전달 여부만 표현하고 물질별 실제 속도·음량 순위를 제공하지 않는다. 녹음 로딩이 실패하면 기존 합성음으로 계속 진행한다.

## v2.1 · 개념 영상과 조작 활동

- 시설의 네 활동을 완료하면 16초 개념 영상이 자동으로 이어진다. 활동·시설별 증거 노트·인증서에서 다시 볼 수 있다. 자동 재생이 제한되거나 동작 줄이기를 사용하면 직접 재생할 수 있다. 자막은 영상에 표시되며 글 설명도 펼쳐 볼 수 있다.
- 동행하는 파란 새 삐오가 활동별 3단계 힌트를 준다. 힌트를 누르면 다음 조작할 곳을 강조한다.
- 북 쓸어내리기, 소리 상자 드래그, 자 길이 조절과 실시간 파형, 건반 연주, 감지기 배치, 소리 길 연결, 해결 도구 배치, 축제 믹서와 주민 반응을 연결했다. 드래그는 터치·마우스에서 같게 동작하며, 버튼·키보드 조작도 제공한다.
- 팝업 중앙 정렬, 48px 이상 조작 영역, 시설별 노트, 마지막 문제 한 개씩 보기를 적용했다. 설정 도움말과 영상 글 설명은 필요할 때 펼친다.
- 2026-10-22: 구문 검사·38개 테스트·빌드 통과. 20개 활동을 브라우저에서 해결해 배지·영상 5편·정식 인증서까지 검증했다. 세 크기의 활동 60화면·팝업 18화면·최종 질문 15화면을 실측했다. 상세 기록은 [docs/EXPERIENCE-v2.1.md](docs/EXPERIENCE-v2.1.md).

개념 영상(2026-11-09부터 HyperFrames 「삐오의 소리 노트」)을 다시 만들 때는 외장 SSD 임시 폴더를 `TMPDIR`로 잡고 `node films/build-films.mjs`로 `films/<id>/`를 만든 뒤, 각 폴더에서 `hyperframes check --json`으로 오류 0을 확인하고 `node films/render-films.mjs [id]`를 실행한다. 결과는 같은 경로 `media/concepts/<id>.mp4`(1280×720, 16초)와 결론 장면 포스터 `<id>.jpg`로 저장된다. 자막 문장은 `src/concepts.js`에서 가져오므로 문장을 바꾸면 VTT도 함께 고치고 `npm test`(시간표 일치 검사)를 돌린다. 리뷰 기록은 `films/REVIEW.md`. 이전 Pillow 방식 `scripts/render-concepts.py`는 기록용으로만 남겨 두었다.

## v2.2 · 납품 전 고도화 (2026-10-30)

- **타이틀**: 1~4번 형제 프로젝트 메인처럼 전면 배경(018 연구소) + 가운데 3D 로고(`image/branding/title-logo.png`, 기존 029 로고를 1200px로 축소) + 소개 한 줄 + `탐험 시작/이어하기`·`도시 이야기 보기` + 오른쪽 아래 삐오 말풍선. 1920×1080 전자칠판은 크게, 높이 560px 이하 폰 가로는 압축 배치.
- **지도**: 화면을 꽉 채우는 1.6배 확대. 그림의 모래길을 따라 딴 길 폭 안에서 자유롭게 걷고, 막히면 벽을 타고 미끄러진다. 왼쪽 아래에 방향 패드·`손으로 둘러보기`·`지도 한눈에 보기`, 오른쪽 아래에 다음 장소 버튼(문 앞에서는 `들어가기`)이 있다. 다시 걸으면 탐험가를 따라간다. 시설을 복구할수록 어스름이 걷히고 그 시설 색의 울림새 주민이 나타난다.
- **교사용 전체 해금**: 활동·최종·결과 화면에서 왼쪽 아래 `← →`(키보드 방향키 포함)로 한 단계씩, 오른쪽 아래 `다음 스테이지`로 다음 시설 첫 활동까지 이동한다. 증거·인증 기록은 채우지 않는다.
- **용량**: 실행 에셋 47.2MB → 16.9MB. 불투명 배경 10장·마을 지도·캐릭터 시트는 같은 해상도 JPEG(품질 86), 투명 소품 10개는 긴 변 720px PNG. 원본은 `_unused/originals-20261029/`(git 제외, 원본은 이전 커밋에도 있음).
- **오프라인·공유**: `sw.js`(HTML은 네트워크 우선, 나머지는 캐시 우선, 영상 제외)와 `manifest.webmanifest`, 아이콘 192/512, 공유 미리보기 `image/og/ullim-og.jpg`(1200×630). 서비스워커는 localhost에서는 꺼져 있고 `?sw`를 붙이면 켜진다. `index.html`의 og:image·twitter:image는 위 운영 사이트의 절대 주소를 사용한다.
- 아이콘·공유 이미지는 `scripts/compose-share-art.swift`로 기존 배경·로고·삐오를 합성해 만들었다(새 생성 이미지 없음).
